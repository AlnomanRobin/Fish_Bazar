# 🐟 FishBazar — বাংলাদেশের সেরা অনলাইন মাছের বাজার

FishBazar is a modern, responsive, multi-vendor online fish marketplace platform designed for Bangladesh.

## 🌟 Features

- **Storefront & Catalog**: Browse fresh fish across river and sea categories (Padma, Meghna, Bay of Bengal, Sundarban).
- **Advanced Filtering & Search**: Real-time autocomplete search, price slider, and category tags.
- **Product Customization**: Fish weight selector and custom cleaning options (Whole, Cleaned, Fillet).
- **Cart & Checkout**: Multi-item cart calculation with district-based dynamic delivery fee.
- **Payment Gateway Simulation**: Full workflow for bKash, Nagad, Card, and Cash on Delivery (COD).
- **Order Tracking**: Customer order history with 1-click re-order.
- **Multi-Role Dashboards**:
  - 👤 **Customer Dashboard**: Track recent orders, delivery addresses, and spending.
  - 🏪 **Seller Dashboard**: Manage inventory, publish products, monitor monthly revenue, and process orders.
  - 👨‍💼 **Admin Dashboard**: Platform-wide analytics, seller approvals, and order monitoring.
- **1-Click Demo Logins**: Fast testing with pre-configured Customer, Seller, and Admin accounts.

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/AlnomanRobin/Fish_Bazar.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Fish_Bazar
   ```
3. Open `frontend/index.html` in your browser or run a local static server:
   ```bash
   python -m http.server 3000 --directory frontend
   # or
   npx serve frontend
   ```
4. Visit `http://localhost:3000` in your web browser.

## 🛠️ Technology Stack

- **HTML5 & CSS3** (Custom Design System, Flexbox/CSS Grid, CSS Variables)
- **Vanilla JavaScript (ES6+ Modules)**
- **Responsive Layout** (Mobile, Tablet, Desktop)
